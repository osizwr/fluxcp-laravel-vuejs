## Why not use a general-purpose database site

Because those describe a different server. Drop rates, stats, spawn points and
item effects are all things a server can change, and most do. The
[items](/items) and [monsters](/monsters) pages here are built from this
server's own database files, so what they say is what this server will
actually do.

## Items

Search by name, or filter by type and job. An item's page shows what it is,
what it does, where it drops from and what it sells for.

Some servers hide items that exist in the database but are not obtainable yet
— an unreleased event reward, a piece of a system still being built. If
something is missing, that is usually why rather than an oversight.

## Monsters

The same, in the other direction: a monster's page shows its stats, where it
spawns and what it drops, with the rates this server uses. Searching an item
and searching the monster that carries it are two ways of asking the same
question, and both work.

## What the numbers mean

A drop rate is the chance per kill, before anything that modifies it. Server
rate settings, a party bonus, an item that improves drops — none of those are
folded into the figure shown, because they depend on who is asking. Treat the
number as the base the rest is applied to.
