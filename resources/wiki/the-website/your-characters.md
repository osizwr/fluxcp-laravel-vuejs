[Characters](/characters) lists every character on your account, and each one
has a page of its own.

## What a character page shows

Appearance, job and level, where the character is, how much Zeny it is
carrying, and what it has equipped and stored. Guild and party membership
too, where the character has either.

## Why a number might look wrong

The website reads the same database the game writes to, but it reads it from
outside. Some values are held in the map server's memory while a character is
logged in and only written out when it logs off, so a character that is in the
world right now may show the state it was in when it last saved rather than
the state it is in this second.

Log the character out and reload the page. If the number is still wrong after
that, it is worth reporting.

## What is not here

Anything that would let somebody follow another player around. Where a
character is standing is only shown to the account that owns it, and a
character whose owner has asked to be hidden is left out of the public
listings entirely rather than being shown with its position blanked — a count
of one on an unusual map identifies somebody just as well as a name does.
