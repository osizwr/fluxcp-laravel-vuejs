One account is used for both the game and this website. Registering here is
the only registration there is.

## What you need

An account name, a password and an e-mail address. The name and password are
what the game client will ask for; the e-mail address is what gets you back in
if you forget the password, so use one you can actually read.

## The rules

The exact limits are set by whoever runs this server, and the registration
form shows them as you type rather than making you guess:

- **Account names** are usually letters, numbers and underscores, with a
  minimum and maximum length. They cannot be changed afterwards, so pick one
  you will not mind typing for a long time.
- **Passwords** have a minimum length and may require a mix of upper case,
  lower case, numbers or symbols. The form tells you which requirements are
  still unmet before you submit.

Your account name is not your character name. Characters are made in the game,
and the name other players see is the character's.

## After you register

Depending on how this server is set up, one of two things happens:

- **You can sign in immediately.** Nothing else to do.
- **You are sent a confirmation code by e-mail.** Enter it on the page that
  appears after registering. Until you do, the account exists but cannot sign
  in — which is also why an unconfirmed account cannot be used to play. If the
  message has not arrived after a few minutes, check the spam folder, then ask
  for a new code; the old one stops working as soon as a new one is sent.

## If you forget the password

Use the "forgot your password" link on the sign-in page. A reset link is sent
to the address the account was registered with, and it expires, so use it when
it arrives rather than later. If you no longer have access to that address,
this is a question for the server's staff rather than something the website
can solve for you — there is no way to prove ownership of an account without
it.
