This is the player guide. It covers getting into the game, what this website
can do for your account, and the questions that come up often enough to be
worth writing down.

## Three steps to playing

1. **Make an account.** One account covers both this website and the game
   itself — there is no second registration.
   See [Creating an account](/wiki/getting-started/creating-an-account).
2. **Get the client.** The game runs from files you download once and then
   keep patched.
   See [Downloading the client](/wiki/getting-started/downloading-the-client).
3. **Sign in and play.** The launcher asks for the same name and password you
   registered with.

Nothing else is required. You do not need to download anything to use this
website, and you do not need to visit this website again after you have an
account, although it is where you will come to reset a password, check the
ladders or look an item up.

## What this website is for

It is the control panel for the server. It reads the same database the game
does, so what you see here is what the game sees:

- **Your account** — change your password or e-mail address, and see where and
  when your account has been signed into.
- **Your characters** — what you have made, what they look like, where they
  are and what they are carrying.
- **Rankings** — who is ahead, on whichever ladders this server keeps.
- **The databases** — every item and monster, searchable, with the numbers the
  server actually uses rather than the ones a different server uses.
- **Who is online** — how busy the world is right now.

## If something here is wrong

This guide is written by the people who run the server, and a guide drifts
away from the game the moment anything changes. If a page says something the
game does not do, say so — in Discord, or wherever this server takes
questions. It is a two-minute fix for whoever maintains these pages, and it
saves the next person the same confusion.
