## Is the account I made here the same one I use in the game?

Yes. There is one account, and registering on this website is what creates it.

## I registered but I cannot sign in.

If this server confirms accounts by e-mail, the account cannot sign in until
the code has been entered. Check your inbox, then the spam folder, then ask
for a new code — the previous one stops working once a new one is sent.

If the account is confirmed and the password is right, check the front page:
the login server may simply be down.

## I have forgotten my password.

Use the forgotten-password link on the sign-in page. The reset is sent to the
address the account was registered with, and it expires.

## I have forgotten which e-mail address I used.

The website cannot tell you, and cannot reset an account without it — that is
what stops anybody else doing the same thing to your account. Ask the
server's staff.

## Can I change my account name?

No. Character names are a separate matter and some servers offer a rename
service in game; the account name is fixed from registration.

## Why does my character show the wrong level or Zeny here?

Some values are only written to the database when a character logs out, so a
character that is online may show its last saved state. Log it out and reload
the page.

## Is it safe to install the client?

It is the same kind of program as any other game you install. Unpack it into
an empty folder of its own, run the launcher rather than the game executable,
and let the patcher finish before you press play. If your antivirus objects to
the patcher replacing files, allow the game's folder — that is the one thing
a patcher does that looks, to an antivirus, like something it should stop.

## Can I play on more than one machine?

Yes — the account is on the server, not on your computer. Whether you may be
logged in twice at once is a server rule rather than a technical one, and a
question for the staff.

## Can staff see my password?

No. This panel never displays a password, and the columns the old control
panel software used to log them in are not written. If anybody asks you for
your password, including somebody claiming to be staff, they are not staff.
