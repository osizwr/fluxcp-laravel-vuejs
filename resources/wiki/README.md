# The wiki

The pages under here are served at `/wiki`. One directory per section, one
Markdown file per page, and the names on disk are the URL:

    getting-started/creating-an-account.md  ->  /wiki/getting-started/creating-an-account

**The pages that ship with the panel are a starting point, not your guide.**
They describe what this control panel does, because that is the only thing the
panel can know about your server. Everything that makes your server yours --
your rates, your custom systems, your events, your commands -- is for you to
write, and until you do, the wiki is a guide to a website rather than to a
game.

Rewrite them, delete the ones that do not apply, and add sections of your own.
Nothing here is referenced by code: a page exists because the file exists.

Full guide, including the front matter each file carries:
[`docs/WIKI.md`](../../docs/WIKI.md).

This file is not a page. Only directories are read, so anything sitting at the
top level -- this README, a draft, a folder of images -- is left alone.
